# اختصارات

صفحة عربية بسيطة لنشر اختصارات الآيفون ومشاركتها مع الأصدقاء والعائلة.

## إضافة اختصار

1. افتح الاختصار في تطبيق **الاختصارات** على الآيفون.
2. اضغط زر المشاركة، ثم اختر **نسخ رابط iCloud**.
3. افتح `docs/shortcuts.js` وأضف اسم الاختصار ووصفه والرابط داخل القائمة.
4. ارفع التغييرات إلى GitHub.

## نشر الصفحة على GitHub Pages

تم إعداد النشر التلقائي مسبقًا باستخدام **GitHub Actions**. للتحقق من الإعداد، افتح من صفحة المستودع:

- **Settings → Pages**
- **Source:** GitHub Actions

عند رفع أي تعديل إلى الفرع `main`، تُنشر محتويات مجلد `docs` تلقائيًا. ويمكن متابعة حالة النشر من تبويب **Actions**.

رابط الصفحة: https://adelss12.github.io/shortcuts/

> ملاحظة: الرسم المستخدم مستوحى بصريًا من فكرة تطبيق الاختصارات، لكنه ليس شعار Apple الرسمي.
